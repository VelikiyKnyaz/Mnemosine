# Documento Maestro

El Documento Maestro v0.1 se mantiene fuera del árbol importable de la
aplicación porque Expo Snack intenta procesar todos los archivos binarios del
repositorio como recursos de la app y rechaza el PDF.

La versión revisada permanece disponible en el historial del repositorio:

[Abrir Mnemosine — Documento Maestro v0.1](https://github.com/VelikiyKnyaz/Mnemosine/blob/1c3dbe293e8409982ce12547ceb829b79a2b7d50/docs/Mnemosine_Documento_Maestro_v0.1.pdf)

Para futuras versiones conviene publicar los documentos maestros en una
ubicación separada de la rama que se importa directamente en Snack.
